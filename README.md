# Hochzeitseinladung Osayamen & George

Eine statische, responsive Hochzeitswebsite für GitHub Pages. Es ist kein Backend nötig.

## In VS Code öffnen

1. Diesen Ordner entpacken bzw. speichern.
2. In VS Code: **Datei → Ordner öffnen** und `Osayamen-George-Hochzeit` auswählen.
3. Optional die Erweiterung **Live Server** installieren.
4. Rechtsklick auf `index.html` → **Open with Live Server**.

## Vor der Veröffentlichung ändern

- In `script.js` die WhatsApp-Nummer ersetzen.
- In `index.html` RSVP-Frist, Anfahrts-Platzhalter und Texte prüfen.
- `assets/favicon.svg` durch das endgültige Logo ersetzen, Dateiname möglichst beibehalten.
- Menü-PDFs nach `menus/speisekarte.pdf` und `menus/pizzakarte.pdf` kopieren und die Hinweise in `index.html` aktivieren.

## GitHub Pages

Ein öffentliches Repository anlegen, z. B. `osayamen-george-hochzeit`. Alle Dateien direkt in den Hauptordner des Repositories hochladen. Dann **Settings → Pages → Deploy from a branch → main → /(root)** wählen.

Die eigene Domain wird erst verbunden, wenn die GitHub-Pages-Adresse funktioniert.
